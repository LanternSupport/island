# LanternX - Islands Hub

Official script hub for Roblox Islands, powered by [LanternLib](https://github.com/LanternSupport/LanternLib).

## 🚀 Quick Execution

Run the loader script in your Roblox executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/LanternSupport/island/main/Loader.lua"))()
```

## 📂 Repository Contents

```text
island/
├── Loader.lua      # Key system loader (fetches UI from LanternLib, launches LanternX)

```
